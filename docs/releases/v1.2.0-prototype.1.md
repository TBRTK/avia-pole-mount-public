# v1.2.0-prototype.1 - first public prototype

This pre-release packages the cleaned Avia 35 mm pole mount with the Emlid Reach RS4 Pro reference assembly.

## Downloads

- `Avia_35mm_v1.2.0-prototype.1.zip`: all three FreeCAD versions, three printable-part STEP files, three STL files, the Emlid reference STEP, documentation, scripts, animation and complete-setup image. No Git history or private original files are included.
- `Avia_35mm_assembly_en.gif`: 18-second English animation, including the final complete-setup illustration.
- `Avia_35mm_complete_setup_en.png`: English concept image, with Avia facing away from the person and the RPi enclosure below the gripping hand.
- `SHA256SUMS.txt`: checksums of the three downloads above. The ZIP also contains a per-file manifest.

Open `cad/Avia_PoleMount_35mm_V1.2_Public.FCStd` for the current prototype. V1.0/V1.1 are retained historical designs. STL units are millimetres; export coordinates are assembly coordinates, so arrange and orient parts in the slicer.

## Changes and checks

All project-facing text, illustration callouts, animation captions and FreeCAD labels/notes are English. Emlid content is described as manufacturer reference geometry with its own source/copyright notice. Native bracket shapes and existing print exports are unchanged. CAD files reopen and recompute; geometry members are byte-identical to the pre-translation versions. Images and all GIF frames were decoded and visually checked. ZIP CRCs, embedded file hashes and release-asset checksums are verified.

**Prototype - physical validation pending.** No working-load rating or tightening torque is specified. Fit, full-thread engagement, actual cable/camera/radio clearances, grip, creep, wear and complete-system calibration remain to be established. The illustration is not to scale; its RPi enclosure is not a dimensioned enclosure or mounting design.
