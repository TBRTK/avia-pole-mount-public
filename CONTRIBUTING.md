# Contributing

V1.2 remains a prototype with physical validation pending. Read [limitations](docs/LIMITATIONS.md), [hardware](docs/HARDWARE.md), [licence scope](LICENSE.md) and [publication boundary](docs/HISTORY_CLEANUP.md). Credit TBRTK for the owner's bracket designs. Emlid manufacturer CAD has a separate permission record; do not assume that the owner's approval grants your intended reuse. No Livox solid belongs in the public edition.

Use the retained issue templates for fit/assembly, print/test experience or improvements. Include exact version/file SHA256, printer/material/settings/orientation, measured pole/part/hardware dimensions, test load/temperature/duration and photographs with a scale. Distinguish observations from calculations; CAD clearance is not measured strength.

Retain previous user designs and original evidence privately. Make changes in a new version and update native parameters, hardware, assembly/access checks and own-part exports together. Keep machine paths, secrets, backups and unapproved manufacturer materials out of public files. Parameter changes are new unqualified configurations.
