# Clean CAD

Current prototype: `Avia_PoleMount_35mm_V1.2_Public.FCStd`. V1.0/V1.1 preserve historical native user bracket designs with independent replacement references. Only V1.2 includes the pole-top RS4 Pro.

The Public suffix distinguishes copies with rebuilt Livox references from original private files. V1.2 also embeds the official Emlid RS4 Pro CAD under owner-stated permission; it is excluded from TBRTK's licence. Parameters remain editable. Default views show final bracket, hardware, pole, independent Avia block and actual RS4 Pro. Enable `V12_FOVReference` for the conservative FOV; keep intermediate construction hidden.
